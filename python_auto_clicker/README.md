# Python Auto Clicker

This folder contains a simple Python GUI version of the C# auto clicker.

## Run it

1. Install the dependency:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the app:
   ```bash
   python main.py
   ```

## Features

- Add mouse click actions
- Add keyboard actions
- Add text typing actions
- Set delays between actions
- Save and load action lists
